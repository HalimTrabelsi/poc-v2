  MLflow Integration — Quick Start Guide
═════════════════════════════════════════════════════════════════════════════

🚀 START HERE (5 minutes)
─────────────────────────────────────────────────────────────────────────────

1. Start MLflow Server
   $ docker compose -f docker-compose.full.yml up mlflow -d

2. Verify it's running
   $ curl http://localhost:5000/health
   Expected: {"status":"ok"}

3. Run training (logs to MLflow automatically)
   $ cd fraud-detection-engine
   $ python ml/scripts/train_robust.py

4. View MLflow UI
   Open: http://localhost:5000
   Look for experiment: "fraud_detection_xgboost"

5. View Streamlit Dashboard
   $ streamlit run ml/dashboards/mlflow_dashboard.py
   Open: http://localhost:8502

🐍 Python API Examples
─────────────────────────────────────────────────────────────────────────────

# Get best model by ROC-AUC
import mlflow
mlflow.set_tracking_uri("http://localhost:5000")
exp = mlflow.get_experiment_by_name("fraud_detection_xgboost")
runs = mlflow.search_runs(
    experiment_ids=[exp.experiment_id],
    order_by=["metrics.xgboost/roc_auc DESC"],
    max_results=1
)
best = runs.iloc[0]
print(f"Best ROC-AUC: {best['metrics.xgboost/roc_auc']:.4f}")

# Load the model
model = mlflow.sklearn.load_model(f"runs:/{best['run_id']}/xgboost_model")

# Get dataset info
import json
artifacts = mlflow.artifacts.download_artifacts(
    run_id=best["run_id"],
    artifact_path="dataset_info.json"
)

🛠️  Common Commands

# Start/stop MLflow
docker compose up mlflow -d              # Start
docker compose down                      # Stop (keeps data in volume)

# Train with tracking
python ml/scripts/train_robust.py

# View stored artifacts
docker exec mlflow-server ls -la /mlflow/mlruns/1/

# Check a specific artifact
docker exec mlflow-server cat \
  /mlflow/mlruns/1/abc123/artifacts/dataset_info.json

# List all experiments (Python)
python -c "
import mlflow
mlflow.set_tracking_uri('http://localhost:5000')
exps = mlflow.search_experiments()
for e in exps: print(e.name)
"

❓ Troubleshooting
─────────────────────────────────────────────────────────────────────────────

Q: MLflow UI shows "No Experiments"
A: (1) Check server: curl http://localhost:5000/health
   (2) Check training logged: grep "Ended MLflow run" /tmp/mlflow_training.log
   (3) Check volume: docker exec mlflow-server ls /mlflow/mlruns/

Q: Training doesn't log to MLflow
A: (1) Check mlflow installed: docker exec fraud-engine pip list | grep mlflow
   (2) Check URI: echo $MLFLOW_TRACKING_URI in container
   (3) Check server running: curl http://localhost:5000/health

Q: Streamlit dashboard loads but no data
A: (1) Run training first: python ml/scripts/train_robust.py
   (2) Wait 30 seconds
   (3) Refresh page

Q: Artifacts not showing
A: (1) Check they exist: docker exec mlflow-server ls /mlflow/mlruns/1/*/artifacts/
   (2) Check permissions: docker exec mlflow-server ls -la /mlflow/
